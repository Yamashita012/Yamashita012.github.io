Local Privilege Escalation Windows & Linux cheat sheet

Every technique below moves from enumeration to exploitation to cleanup awareness. Each command block explains what it does and why it works — treat this as a field companion, not a substitute for understanding the underlying misconfiguration.

⚠ Scope discipline. Only run these against systems you are explicitly authorized to test (signed rules of engagement / your own lab). Local privilege escalation almost always creates artifacts — new processes, scheduled tasks, registry keys, SUID bits, cron entries. Log what you change and revert it during cleanup.
Field notes are a starting point, not a replacement for reading the actual documentation of the tool or misconfiguration class you're exploiting. Cross-reference with GTFOBins, LOLBAS, HackTricks, and the official vendor advisories before relying on any single technique in a live engagement.
